# limbo-movielist

A small Flask watchlist page from 2022, built while following a Flask tutorial. Kept as is: rough early code.

## Preview locally

```bash
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000 (on macOS, if port 5000 is taken by AirPlay Receiver, use `flask run --port 5055`).
